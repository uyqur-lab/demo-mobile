# Tender ro'yxati — nom bo'yicha qidiruv

## Muammo

Filtrlar qo'shilgandan keyin ham ta'minotchi aniq bir tenderni nomi bo'yicha
topa olmayapti — ro'yxatni qo'lda ko'zdan kechirishga majbur.

## Foydalanuvchi hikoyasi

Ta'minotchi sifatida men tenderni nomi bo'yicha qidirmoqchiman, chunki men
qidirayotgan tenderning nomini bilaman.

## Qabul mezonlari

- AC-1 [MB] EVENT: QACHONKI qidiruv matni kiritilsa, ro'yxatda faqat nomida shu matn bor tenderlar ko'rsatiladi
- AC-2 [MB] UBIQUITOUS: qidiruv katta-kichik harfga sezgir emas
- AC-3 [MB] EVENT: QACHONKI qidiruv matni tozalansa, to'liq ro'yxat qaytadi
- AC-4 [MB] manual: qidiruv maydoni klaviatura ochilganda ekrandan yashirinmaydi

## API kontrakti

Qidiruv klient tomonda amalga oshiriladi — yangi endpoint kerak emas.

## Ko'lamdan tashqari

- Server tomonda qidiruv
- Qidiruv tarixi
